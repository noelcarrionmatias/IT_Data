# Contenido:
Tareas realizadas durante el Bootcamp Data Analytics impartido por Barcelona Activa con colaboración de la UPC (Universitat Politècnica de Barcelona). Consta de un bloque de fundamentos en el cual se imparte conceptos claves del análisis de datos y aprender su importancia. El segundo bloque de especialización está formado por "sprints", donde cada uno se especializa en un apartado del análisis de datos. Al finalizar todo el proceso se realiza un proyecto final.

## Fundamentos:
### SQL:
Consultas básicas y avanzadas, creación de datasets, tablas y modificación de datos. Tipos de relación y modelado.

### Power BI:
Conceptos de visualización con Power BI.

### Python:
Tipos de datos en Python, listas, funciones, diccionarios.
Libreria Pandas (manejo de DataFrames, filtrado...)

## Especialización:

### Sprint 1:
De carácter introductorio y explicando los software necesarios para los siguientes "sprints".

### Sprint 2: 
Nociones básicas SQL: Claves (PK y FK), vistas, índices, subconsultas, manipulación de datos, diagramas y creación de tablas y bases de datos.

### Sprint 3:
Introducción a BigQuery: Separación de almacenamiento, arquitectura, creación de infraestructura, CTE, gestión de errores, control de costes, transformación y calidad del dato.

### Sprint 4:
BigQuery avanzado: Arquitectura y optimización de costes, SQL analítico avanzado (funciones de ventana), automatización, vistas materializadas, conexión y visualización con DataStudio.

### Sprint 5:
Bases de datos no relacionales en MongoDB: diferencias entre BBDD SQL y NoSQL, tipos de datos y operaciones CRUD básicas. 

### Sprint 6:
Fundamentos de la estadística descriptiva: estadísticas de centralidad, dispersión, visualización específicas, rellaciones, regresión lineal y estadística inferencial y tests estadísticos.

### Sprint 7:
Nociones y conocimientos en Python: dominar el funcionamiento de listas, diccionarios, bucles y crear funciones.

### Sprint 8:
Analítica de datos en Python: Desarrollo de procesos ETL, transformación y análisis de datos con Pandas y NumPy, gestión de archivos Excel y JSON, creación de visualizaciones con Matplotlib y Seaborn y automatización de tareas de procesamiento y exportación de datos.

### Sprint 9:
Visualización de datos: Python como herramienta de análisis visual para interpretar datos y extraer conclusiones de valor para el negocio. El enfoque principal está en el criterio analítico y el storytelling basado en datos. Google Colab como motor principal.
